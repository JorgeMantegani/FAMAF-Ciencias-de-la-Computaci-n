# COMPILACION Y EJECUCION:
<p>El proyecto se puede compilar ejecutando el siguiente comando en la consola:

`make`

Para analizar los casos, ejecutar el siguiente comando, donde X es el caso que se quiere analizar:<p> 

`./redes26lab3g26 -u Cmdenv -c CasoX` 

<p>Adicionalmente, para el caso de competición, ejecutar:

`./redes26lab3g26 -u Cmdenv -c Competicion`

Tener en cuenta que casos 1 y 2 pertenecen a la Parte 1 (correspondiente al tag "v0.1-parte1"), mientras que los casos 3 y 4 pertenecen a la Parte 2 (correspondiente al tag "v1.0-final").<p>
